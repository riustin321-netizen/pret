# Componentă experimentală GameUI HellBoost

`GameUI.dll` din acest folder este construită din codul propriu `native/gameui/proxy.cpp`; nu este biblioteca Valve furnizată de utilizator. Nu o instala singură și nu o copia în folderul Steam.

Folosește kitul `../HellBoost-gameui-test-x86.zip` și instrucțiunile `docs/gameui-test.md`. Acest binar MinGW este păstrat aici pentru verificarea ABI în Windows, cu o bibliotecă originală simulată construită cu MSVC. Biblioteca originală a jocului nu este publicată.
